# Memo Studio — Field Notes

ブラウザだけで動作する、画像・音声入力・テンプレートに対応した**メモ／フィールドノートアプリ**です。
すべてのデータは端末内の IndexedDB に保存され、サーバーや外部送信は一切ありません。フレームワーク不要、`index.html` を開くだけで利用できます。

---

## 主な機能

### 📝 メモ管理
- メモの新規作成・編集・削除（タイトル／タグ／本文）
- 作成日時・更新日時の自動記録、本文の文字数カウント
- 未保存の変更を検知し、画面切り替えやページ離脱時に確認（編集内容の喪失を防止）
- `Ctrl+S` で保存

### 🔍 検索・タグ
- タイトル・タグによるインクリメンタル検索
- タグでの絞り込み（使用回数つきタグバー）
- カンマ区切りで複数タグを付与、入力中のサジェスト補完
- タグマスタ管理（登録済みタグの一括管理・削除）

### 🗂 フォーマット（テンプレート）
- 定型メモのフォーマットを登録・管理
- カーソル位置へワンクリック挿入
- 置換トークン `{{date}}` `{{time}}` `{{datetime}}` `{{cursor}}` に対応

### 🖼 画像
- 画像の追加（ファイル選択／ドラッグ&ドロップ／本文への `Ctrl+V` 貼り付け）
- サムネイル一覧（表示サイズ調整可）
- ライトボックスで拡大表示（ホイールズーム・ドラッグ移動・前後切替）
- 画像はメモごとに紐づけて保存

### 🎤 音声入力
- Web Speech API による日本語のリアルタイム音声入力
- 本文へ直接書き起こし（録音時間表示つき）
- 非対応ブラウザでは自動的に無効化（グレースフルデグラデーション）

### 💾 データの保存・入出力
- IndexedDB によるローカル永続化
- JSON でのエクスポート／インポート（メモ・タグ・フォーマット）
- **Minutes Memo Pro（議事録アプリ）の出力データの取り込みに対応**
- メモ内容のテキストコピー

### 🎛 UI / 操作性
- サイドバー（メニュー）の折り畳み（滑らかなアニメーション）
- 画像パネルの開閉、ゆったり広い本文エリア
- レスポンシブ対応（PC／タブレット／スマホ）
- トースト通知・確認ダイアログによる分かりやすいフィードバック
- 表示設定（サムネイルサイズ、パネルの開閉状態など）を自動記憶

## 使い方

1. `index.html` をブラウザで開きます（インストール不要）。
2. 「**新規メモ**」からメモを作成し、タイトル・タグ・本文を入力します。
3. 必要に応じて画像の添付、音声入力、フォーマット適用を行います。
4. 「**保存**」または `Ctrl+S` で保存します（データは端末内に残ります）。

> 💡 音声入力・マイク機能は、セキュリティ上の理由から `file://` で開いた場合に制限されることがあります。
> その際は簡易な Web サーバー経由（例: `python3 -m http.server`）でアクセスしてください。

## データのインポート / エクスポート

トップバーのアイコンから操作します。

| 操作 | 内容 |
| --- | --- |
| エクスポート | メモ・タグ・フォーマットを JSON ファイルとして保存します（画像はファイルには含まれません）。 |
| インポート | JSON ファイルを読み込み、現在のデータに統合します。 |

### Minutes Memo Pro データの取り込み

議事録アプリ **Minutes Memo Pro** が出力する JSON も、形式を自動判別して取り込めます。

- **全データ形式**（`sessions` / `masters` / `flagMasters`）と **単一会議形式** の両方に対応
- 会議ごとに 1 件のメモへ変換し、以下を引き継ぎます。
  - 会議タグ → メモのタグ、開催日 → 作成・更新日時
  - 各メモの本文・フラグ（【TODO】等）→ 本文へ時系列順に展開
  - 添付画像（data URL）→ 画像として復元
- 取り込みは既存データへ**追加**されます（既存メモは上書きされません）。

## 技術仕様

- **構成**: Pure HTML / CSS / JavaScript（ビルド・依存ライブラリなし）
- **永続化**: IndexedDB（`memos` / `images` / `formats` / `tags` / `prefs` ストア）
- **音声入力**: Web Speech API（`webkitSpeechRecognition`）
- **アイコン**: Font Awesome 6（CDN）
- **動作環境**: Chrome / Edge など最新の Chromium 系ブラウザを推奨
  （IndexedDB 非対応環境・シークレットモードでは保存機能が制限される場合があります）

### ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面構造（マークアップ） |
| `style.css` | スタイル・レイアウト・レスポンシブ |
| `script.js` | アプリのロジック（保存・検索・画像・音声・入出力など） |

---

## プライバシー

すべてのデータはブラウザの IndexedDB 内にのみ保存され、外部に送信されることはありません。
別の端末・ブラウザへ移行する場合は、エクスポート機能でバックアップを取得してください。
