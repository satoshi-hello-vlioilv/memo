# Memo Studio — Field Notes

ブラウザだけで動作する、画像・音声入力・テンプレートに対応した**メモ／フィールドノートアプリ**です。
すべてのデータは端末内の IndexedDB に保存され、サーバーや外部送信は一切ありません。フレームワーク不要、`index.html` を開くだけで利用できます。

---

## 主な機能

### 📝 メモ管理
- メモの新規作成・編集・削除（タイトル／タグ／本文）
- 作成日時・更新日時の自動記録、本文の文字数カウント
- 未保存の変更を検知し、画面切り替えやページ離脱時に確認（編集内容の喪失を防止）
- **自動保存（下書き）**: 保存前の内容を数秒おきに退避し、タブが落ちても次回起動時に復元
- **ゴミ箱**: 削除したメモは 30 日間保持し、いつでも復元可能（完全削除も選択可）
- **元に戻す／やり直し**: 書式・画像・貼り付けを含むすべての編集操作に対応
- 目印（付箋）で重要・要対応などを色分け。「ピン」を付けたメモは一覧の先頭に固定
- `Ctrl+S` で保存

### 🔍 検索・整理
- タイトル・タグ・本文のインクリメンタル検索（検索対象は個別に切替可能）
- **検索構文**: 空白区切りの AND 検索、`"句"`、`-除外`、`tag:` `mark:` `is:` `date:` `title:` `body:`
- タグ・目印・画像／添付の有無での絞り込み（使用回数つきバー）
- **絞り込みの一本化**: 効いている条件を「絞り込み」バーに1列で表示し、× で個別に解除。
  チップを押すと検索欄にも `tag:業務` が入り、逆に打ち込めばチップも選択表示になります
- 並び替え（更新日／作成日／タイトル・昇降順）、日付グループ表示
- **一括操作**: 複数のメモを選んでタグ付与・目印・ゴミ箱へ移動・選択分の書き出し
- カンマ区切りで複数タグを付与、入力中のサジェスト補完
- タグマスタ管理（登録・**リネーム／統合**・削除）

### ✍️ 本文の書式
- 太字・斜体・文字サイズ・文字色・ハイライト・フォント・リンク
- **段落書式**: 見出し（大・中・小）・箇条書き・チェックリスト
  （チェックボックスはクリックで完了／未完了を切替、Enter で次の項目へ続く）
- **メモ内検索・置換**（`Ctrl+F`）: 件数表示・前後移動・1件ずつ／一括置換
- 書式を除いた貼り付け（`Ctrl+Shift+V`）と、貼り付け時の書式の自動変換

### 🗂 フォーマット（テンプレート）
- 定型メモのフォーマットを登録・管理
- カーソル位置へワンクリック挿入
- 置換トークン `{{date}}` `{{time}}` `{{datetime}}` `{{cursor}}` に対応

### 🖼 画像
- 画像の追加（ファイル選択／ドラッグ&ドロップ／本文への `Ctrl+V` 貼り付け）
- サムネイル一覧（表示サイズ調整可）
- ライトボックスで拡大表示（ホイールズーム・ドラッグ移動・前後切替）
- 画像はメモごとに紐づけて保存

### 🎤 音声入力
- Web Speech API による日本語のリアルタイム音声入力
- 本文へ直接書き起こし（録音時間表示つき）
- 非対応ブラウザでは自動的に無効化（グレースフルデグラデーション）

### 💾 データの保存・入出力
- IndexedDB によるローカル永続化
- **完全バックアップ**: 画像・添付ファイルまで含めた JSON の書き出し／復元
- 取り込みは既存メモを上書きしない（ID を振り直し、重複はスキップを選択可）
- **Minutes Memo Pro（議事録アプリ）の出力データの取り込みに対応**
- メモ内容のテキストコピー（段落書式は「・」「☑」などの記号に変換）

### 🎛 UI / 操作性
- サイドバー（メニュー）の折り畳み（滑らかなアニメーション）
- 画像パネルの開閉、ゆったり広い本文エリア
- レスポンシブ対応（PC／タブレット／スマホ）
  - 幅 1150px を下回ると画像パネルを自動でたたみ、本文と保存ボタンの場所を確保
  - 幅 768px 以下は「一覧／編集／画像」のタブ切り替え（メモを開くと編集タブへ）
- ツールバーは 1 段。使用頻度の低い操作（フォント・ハイライト・音声入力など）は「…」へ集約
- トースト通知・確認ダイアログによる分かりやすいフィードバック（削除は「元に戻す」付き）
- 表示設定（サムネイルサイズ、パネルの開閉状態、並び順など）を自動記憶
- キーボードショートカット（一覧は `F1` または `?`、管理画面の「キー操作」からも確認可能）

## 使い方

1. `index.html` をブラウザで開きます（インストール不要）。
2. 「**新規メモ**」からメモを作成し、タイトル・タグ・本文を入力します。
3. 必要に応じて画像の添付、音声入力、フォーマット適用を行います。
4. 「**保存**」または `Ctrl+S` で保存します（データは端末内に残ります）。

> 💡 音声入力・マイク機能は、セキュリティ上の理由から `file://` で開いた場合に制限されることがあります。
> その際は簡易な Web サーバー経由（例: `python3 -m http.server`）でアクセスしてください。

### 検索のしかた

検索欄は複数の条件を空白で並べて書けます（すべてを含むメモが対象）。

| 書き方 | 意味 |
| --- | --- |
| `定例 議事録` | 両方を含む |
| `"打ち合わせ 3月"` | 空白を含むひとまとまりの語（`「…」` も可） |
| `-済` | その語を含まない |
| `tag:業務` | タグで絞り込む |
| `mark:重要` | 目印で絞り込む（`mark:none` で目印なし） |
| `is:image` / `is:file` / `is:untagged` | 画像あり／添付あり／タグなし |
| `date:2026-09-18` | 作成日で絞り込む（`date:2026-09`・`date:今日` も可） |
| `after:2026-09-01` / `before:…` | その日以降／以前に作成 |
| `updated:今日` | 更新日で絞り込む |
| `title:議事録` / `body:出席者` | タイトルだけ／本文だけを対象にする |

> ⌨️ キーボードショートカットの一覧は `F1`（または `?`）で開けます。

## データのインポート / エクスポート

トップバーのアイコンから操作します。

| 操作 | 内容 |
| --- | --- |
| エクスポート | メモ・タグ・フォーマットを JSON ファイルとして保存します。書き出し時に **「メモだけ（軽量）」** と **「画像・添付も含める」** を選べます。 |
| インポート | JSON ファイルを読み込み、現在のデータへ**追加**します。既存のメモが上書きされることはありません。 |

> 💾 **端末を移行するときは「画像・添付も含める」を選んでください。** 画像を含まないファイルを
> 取り込むと、本文に貼った画像は「画像未登録」と表示されます。

> ♻️ **取り込みは常に新しいメモとして追加されます。** 取り込んだメモには新しい ID を割り当て、
> 本文中の画像参照もあわせて振り替えるため、手元のメモが書き換わることはありません。
> 同じメモ（作成日時とタイトルが一致）が既にある場合は、**スキップ**するか**両方残す**かを選べます。

> 📥 **ドラッグ&ドロップ取り込み**: JSON ファイルをウィンドウへドラッグ&ドロップするだけでインポートできます。
> ファイル種別は自動判別され、JSON はデータ取り込み・画像ファイルは編集中メモへの添付として処理されます。

### Minutes Memo Pro データの取り込み

議事録アプリ **Minutes Memo Pro** が出力する JSON も、形式を自動判別して取り込めます。

- **全データ形式**（`sessions` / `masters` / `flagMasters`）と **単一会議形式** の両方に対応
- 会議ごとに 1 件のメモへ変換し、以下を引き継ぎます。
  - 会議タグ → メモのタグ、開催日 → 作成・更新日時
  - 各メモの本文・フラグ（【TODO】等）→ 本文へ時系列順に展開
  - 添付画像（data URL）→ 画像として復元
- 取り込みは既存データへ**追加**されます（既存メモは上書きされません）。

## 技術仕様

- **構成**: Pure HTML / CSS / JavaScript（ビルド・依存ライブラリなし）
- **永続化**: IndexedDB v4（`memos` / `images` / `files` / `formats` / `tags` / `prefs` / `drafts` ストア）
  - 旧バージョンのデータベースは起動時に自動で移行されます（検索用テキストの生成など）
- **音声入力**: Web Speech API（`webkitSpeechRecognition`）
- **アイコン**: Font Awesome 6（CDN）
- **動作環境**: Chrome / Edge など最新の Chromium 系ブラウザを推奨
  （IndexedDB 非対応環境・シークレットモードでは保存機能が制限される場合があります）
- **テスト**: `npm test`（Node.js 22 以降の `node:test` のみ。依存パッケージのインストールは不要）
  - 本文の保存形式の往復・検索構文・取り込みの変換など、DOM に依存しない処理を検証します
  - GitHub Actions（`.github/workflows/ci.yml`）で push / PR ごとに実行します

### ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面構造（マークアップ）とスクリプトの読み込み |
| `style.css` | スタイル・レイアウト・レスポンシブ |
| `js/core.js` | 基盤：ユーティリティ、IndexedDB ラッパー、アプリ状態、要素参照、トースト・ダイアログ、設定の永続化 |
| `js/search.js` | 検索：本文マーカーの除去、検索用テキスト、検索構文の解釈と照合（DOM 非依存） |
| `js/body-parse.js` | 本文の保存形式の解釈・組み立て、段落書式の行操作（DOM 非依存） |
| `js/filterbar.js` | 絞り込み条件の一本化：条件チップの組み立てと、チップ操作⇔検索構文の相互反映 |
| `js/list.js` | サイドバーのメモ一覧：検索・絞り込み・検索サジェスト、タグマスタ |
| `js/bulk.js` | 一覧の選択モードと一括操作（タグ・目印・削除・書き出し） |
| `js/trash.js` | ゴミ箱：論理削除・復元・完全削除・期限切れの自動削除 |
| `js/drafts.js` | 自動保存（下書き）の退避と復元 |
| `js/editor.js` | メモの編集・保存・削除と、編集画面まわりの表示状態 |
| `js/body.js` | 本文エディタ：インライン画像、本文テキストと DOM の相互変換、段落書式、改行マーク、カーソル行ハイライト |
| `js/history.js` | 本文の元に戻す／やり直し |
| `js/text-format.js` | 本文の書式設定（太字・斜体・文字サイズ・文字色・ハイライト）とリンク |
| `js/find.js` | メモ内の検索・置換 |
| `js/ctxmenu.js` | 本文エディタの右クリックメニューとクリップボード操作 |
| `js/images.js` | 画像の登録・表示・削除、画像パネル、ライトボックス |
| `js/files.js` | 添付ファイルの登録・一覧・ダウンロード・削除 |
| `js/speech.js` | 音声入力（Web Speech API） |
| `js/formats.js` | カスタムフォーマット（テンプレート）の管理と適用、キー操作一覧 |
| `js/data.js` | エクスポート／インポート、ドラッグ&ドロップ |
| `js/main.js` | イベント結線とアプリの初期化 |
| `tests/` | 依存ライブラリ無しのテスト（`npm test`） |

> スクリプトは ES モジュールではなく通常の `<script>` として依存順に読み込みます。
> ES モジュールは `file://` では読み込めず、「`index.html` を開くだけ」で使えなくなるためです。
> DOM に依存しないファイルは末尾に `module.exports`（ブラウザでは無視される）を置き、
> テストからそのまま読み込めるようにしています。

## プライバシー

すべてのデータはブラウザの IndexedDB 内にのみ保存され、外部に送信されることはありません。
別の端末・ブラウザへ移行する場合は、エクスポート機能で **「画像・添付も含める」** バックアップを
取得してください。
